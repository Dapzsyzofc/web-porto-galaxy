# DAFIAN — Portfolio '26 | Next.js 3D Cosmic Universe

Project portofolio interaktif **Muhammad Dafian** berbasis **Next.js (App Router)**, **Three.js (WebGL 3D Planets & Galaxy)**, **Custom GLSL Gargantua Black Hole Portal Shader**, **Anime.js**, dan **Tailwind CSS** — siap dijalankan di komputer lokal maupun di-*deploy* langsung ke **Vercel**.

## Cara Menjalankan di Komputer Lokal (`localhost:3000`)

1. Ekstrak file `.zip` ini, lalu buka terminal di dalam folder `dafian-cosmic-nextjs`:
   ```bash
   cd dafian-cosmic-nextjs
   npm install
   npm run dev
   ```
2. Buka browser dan akses **`http://localhost:3000`**.
